# Frontend Testing Practice

A frontend testing project built with React, TypeScript, Vite, and Vitest.

The project is focused on learning and practicing frontend testing concepts, including unit testing, React component testing, test-driven development (TDD), test-based development (TBD), and end-to-end testing with Playwright.

## Tech Stack

- React
- TypeScript
- Vite
- Vitest
- React Testing Library
- Testing Library Jest DOM
- Testing Library User Event
- jsdom
- Playwright

## Testing Concepts

- Unit Testing
- Component Testing
- Integration Testing
- End-to-End Testing
- Test-Driven Development (TDD)
- Test-Based Development (TBD)
- Arrange → Act → Assert
- DOM and accessibility-based queries
- User interaction testing
- Assertions and matchers
- Browser testing
